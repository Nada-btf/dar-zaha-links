Dar Zaha - links page

HOW TO PUBLISH (free):
- Netlify: go to app.netlify.com/drop and drag this folder in.
- or GitHub Pages / Cloudflare Pages.
Then turn the page URL into a QR code.

HOW TO UPDATE LATER:
- Logo: already included (embedded in index.html).
- Colors: edit the --accent / --accent2 / --bg values at the top of index.html.
- New links: copy one <a class="btn"> block and change the address and name.
